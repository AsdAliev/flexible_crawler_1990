# 1990 Разработка настраиваемого краулера для сбора данных с интернет страниц



## Аннотация

На текущий момент существует много типовых задач по сбору данных с сайтов из интернет-пространства. 
Зачастую такие задачи решаются с помощью написание краулеров с применением специальных библиотек. 
Алгоритмы обхода сайта, поиска и сбора данных при этому пишутся программистами с использованием различных механизмов (например Scrapy, Apache Nutch).  

Идея проекта в создании типового краулера с использованием библиотеки Scrapy, который сможет принимать на вход стандартное описание алгоритма обхода страницы сайта, а также web-приложения для настройки краулера.
